# Overview
Sales &amp; Financial Analytics dashboard built using MS Excel &amp; Power Query for AtliQ Hardwares. Includes multi-year P&amp;L reporting, customer growth tracking, and market target variance analysis.
This repository contains a comprehensive Sales & Finance Analytics project completed for AtliQ Hardwares, a leading consumer electronics and hardware manufacturer operating globally across B2B, B2C, and e-commerce distribution channels.

The primary objective of this project is to analyze multi-year enterprise datasets to empower decision-makers with actionable insights into revenue growth, customer performance, target variances, and market-by-market profitability (P&L).

# Technical Stack & Tools Used
